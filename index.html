FAQ

Questions practitioners ask first.

What can I use as a starting identifier?
Name, email, phone, address, username, social handle, or IP — any combination works. Seed multiple at once to start a broader graph.
How does hop expansion work?
Round one resolves your seed across all sources. Every new identifier that surfaces — a phone tied to an email, an address linked to a name — becomes a query target in round two. Continues hop by hop until no new entities surface or you stop it. All sources run in parallel each round.
What data sources does OctoProbe integrate?
Six source types: identity and background databases, breach and credential intelligence (billions of records attributed to specific datasets), social footprint across 350+ platforms, dark web and archive search, public-record data lakes (corporate filings, UCC, property, aviation, maritime), and a custom linkage layer for your own data.
How does the MCP integration work?
OctoProbe exposes investigate, expand_node, get_entity_detail, get_source_breakdown, and export_report as callable MCP tools. Connect to Claude Desktop or any MCP client — your agent runs live investigations mid-conversation, in plain language.
What provenance does each result carry?
Every entity is tagged to its source, the specific dataset or breach database (e.g., "LinkedIn 2021 breach," "FAA aircraft registration"), and the exact API call datetime. The JSON export carries a full api_calls list per entity — source label, queried identifier, timestamp, and association count.
Are exports tamper-evident?
Yes. PDF includes the graph image, analyst notes, entity annotations, and source attribution. JSON includes full per-entity provenance. Both are SHA-256 hash-verified at export time — any post-export modification is detectable. Every query, expansion, and export is captured in the audit log.
